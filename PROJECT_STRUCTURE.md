# 📅 Appointment Booking App — Project Structure

## Stack
- **Framework**: Next.js 14 (App Router)
- **ORM**: Prisma
- **Database**: PostgreSQL via Supabase
- **Auth**: NextAuth.js v5
- **Styling**: Tailwind CSS + shadcn/ui
- **Payments**: Stripe (optional)
- **Email**: Resend
- **Validation**: Zod

## Core Data Flow

```
Client visits /book/[providerId]
    → Picks a Service
    → Picks an available Date + Time Slot
        (API: GET /api/availability/slots?providerId=...&date=...)
    → Confirms booking
        (API: POST /api/appointments)
    → Email confirmation sent to both parties
    → Reminders scheduled for 24h and 1h before

Provider visits /admin/calendar
    → Sees all upcoming bookings
    → Can Confirm / Cancel / Mark No-show
    → Sets weekly availability at /admin/availability
```

---

## Key Business Logic — Slot Calculation

```
GET /api/availability/slots?providerId=X&date=2024-03-15&serviceId=Y

1. Fetch provider's Availability for that day of week
2. Fetch all Bookings for that day (PENDING + CONFIRMED)
3. Fetch BlockedSlots for that day
4. Generate all possible slots (service.duration intervals)
5. Filter out: already booked, blocked, past times
6. Return: array of available DateTime slots
```

## Setup Commands

```bash
# 1. Install dependencies
npm install prisma @prisma/client next-auth @auth/prisma-adapter
npm install zod resend stripe
npm install -D @types/node typescript

# 2. Init Prisma
npx prisma init

# 3. Push schema to Supabase
npx prisma db push

# 4. Generate client
npx prisma generate

# 5. Seed database
npx prisma db seed

# 6. Run dev server
npm run dev
```
